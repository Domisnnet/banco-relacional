# 🌍 Dashboard População Mundial

Uma dashboard full stack que consome dados em tempo real de um banco MySQL e exibe os **10 países mais populosos do mundo** com visual moderno, gráfico interativo e tema escuro/claro.

---

## ✨ Funcionalidades

- 📊 Gráfico dinâmico com Chart.js
- 🌙 Tema escuro/claro alternável
- 🐬 Conexão com banco de dados MySQL
- 🌐 Backend em Node.js + Express
- 📁 Estrutura de pastas organizada
- ✅ Responsivo para desktop e mobile
- 🔐 Uso de `.env` para proteger dados sensíveis
